# 错误码定义

> 统一维护文档。所有后端接口错误返回格式：
>
> ```json
> { "code": 40001, "message": "余额不足", "data": null }
> ```
>
> `code = 0` 表示成功，`message = "success"`。
>
> 分段规则：`1xxxx` 通用 / 参数，`2xxxx` 认证 / 权限，`3xxxx` 用户 / 菜单业务，`4xxxx` 订单 / 钱包，`5xxxx` 系统 / 外部依赖。

## 通用（1xxxx）

| code | message | 说明 |
|---|---|---|
| 10001 | 参数错误 | DTO 校验失败、字段缺失、格式非法 |
| 10002 | 资源不存在 | 目标资源不存在或已删除 |
| 10003 | 路由不存在 | 请求了未定义的接口路径 |
| 10004 | 请求过于频繁 | 限流触发（预留，初期不强制） |

## 认证 / 权限（2xxxx）

| code | message | 说明 |
|---|---|---|
| 20001 | 未登录 | 未携带 token 或 token 缺失 |
| 20002 | 登录凭证无效 | 微信 code 换取会话失败 / openid 获取失败 |
| 20003 | 账号或密码错误 | 管理员账号密码错误 |
| 20004 | 账号已被禁用 | 用户或管理员 status = 0 |
| 20005 | 无权限访问 | 非管理员访问管理接口 |
| 40101 | token 过期或无效 | token 过期、签名无效、被篡改 |

## 用户 / 菜单业务（3xxxx）

| code | message | 说明 |
|---|---|---|
| 30001 | 用户不存在 | openid 对应的用户不存在 |
| 31001 | 分类不存在 | menu_category 不存在 |
| 31002 | 菜品不存在 | menu 不存在或已删除 |
| 31003 | 规格项不存在 | menu_spec_item 不存在 |
| 31004 | 公告不存在 | announcement 不存在或已下线 |
| 31005 | 会话不存在 | chat_conversation 不存在 |
| 31006 | 无权访问该会话 | 用户或管理员操作非本人/无权限会话 |
| 31007 | 消息内容不合法 | 聊天消息为空或超过长度限制 |
| 31008 | 菜品上架中，请先下架再删除 | 删除上架状态的菜品（menu.status=1） |
| 31009 | 分类上架中，请先下架再删除 | 删除上架状态的分类（menu_category.status=1） |

## 订单 / 钱包（4xxxx）

| code | message | 说明 |
|---|---|---|
| 40001 | 余额不足 | 扣款失败，不做部分扣款 |
| 40002 | 库存不足 | 菜品库存不够下单数量 |
| 40003 | 菜品已下架 | 菜品 status 非上架 |
| 40004 | 订单状态不允许该操作 | 如取消已完成订单、支付已取消订单 |
| 40005 | 重复提交 | 相同 `client_order_no` 并发/重复请求 |
| 40006 | 订单不存在 | 订单号/ID 不存在 |
| 40007 | 无权操作该订单 | 操作他人订单 |

## 系统 / 外部依赖（5xxxx）

| code | message | 说明 |
|---|---|---|
| 50000 | 系统内部错误 | 未预期的异常（兜底） |
| 50001 | 微信服务调用失败 | code2Session、订阅消息发送失败 |
| 50002 | 文件上传失败 | COS 直传 / 服务端上传异常 |

---

## 使用规范

- **新增错误码**：先在本文件登记，再在代码中使用；不直接复用数字。
- **语义不变**：同一错误码不得在不同场景代表不同含义。
- **服务端为准**：前端展示时优先使用 `message` 文案；`message` 应为用户可读的中文描述。
- **兜底**：Controller 层统一捕获异常，未识别错误一律返回 `50000`。
