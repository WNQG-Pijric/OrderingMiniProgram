# 04-cart：购物车模块（本地缓存，纯前端）

> 前置规则：`docs/prompts/00-project-rule.md`。本模块**无后端接口**。

## 目标

本地购物车：加购、改规格、改数量、删除、选中结算。

## 存储

小程序 `Storage`，key 形如 `cart:<userId>`（按用户隔离）。

## 内容

单条购物车项：

```
{
  "menuId": 1,
  "menuName": "珍珠奶茶",
  "image": "https://...",
  "specIds": [101, 202],        // 所选规格项 ID 列表
  "specText": "半糖/少冰/加珍珠", // 展示用快照
  "unitPrice": 16,              // 展示用单价（基础价+规格加价）
  "count": 2,
  "remark": "不要盖"
}
```

## 接口

v1 无 `/cart` 后端接口；提供前端工具函数（`addItem` / `updateCount` / `removeItem` / `clear` / `getItems` / `computeTotal`）。

## 关键规则（硬性）

- **下单前本地校验**，但最终以下单接口（模块 05）服务端重算为准；本地金额仅供展示。
- 同 `menuId + specIds` 相同则合并数量。
- 规格变更 / 菜品下架后，本地缓存可能过期：进入确认订单页时，需请求最新菜单信息校验并提示更新。
- v2 预留服务端购物车（`/cart` 接口），本模块存储结构需可平滑迁移。

## 输出物

- 小程序端购物车页面（含侧滑删除、数量加减、合计展示）
- 本地缓存工具 `utils/cart.js`
- 与「确认订单」页的数据传递

## 验收标准

1. 加购 / 改量 / 删除 / 清空均在本地持久化，重启小程序不丢失。
2. 相同菜品 + 相同规格自动合并数量。
